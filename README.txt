START HERE
Double-click index.html to open it in your browser.
No install, internet connection, server, or account is required.
Keep index.html, styles.css, bank.js, guide.js, engine.js, app.js, appearance.js, analogies.js, motion.js, and activities.js together.
If opening the ZIP version, extract the entire folder first.

APPEARANCE
Use Hide sidebar in the top bar to give the guide the full available width.
Show sidebar restores navigation. The control remains available during practice.
Theme offers eight palettes: Forest, Ocean, Violet, Amber, Midnight, Cursed
Energy, Hidden Leaf, and Wisteria Night. Themes change the background, texture,
card styling, and accent colors. Sidebar, theme, and motion preferences are
saved locally, independently of practice history.

Text settings offers five built-in font stacks and five sizes: 90%, 100%,
115%, 130%, and 150%. Font and size choices are saved in this browser.

Motion on/off controls scroll reveals, card entrances, answer reveals, and
transitions. Your device reduced-motion setting is always respected. A thin
bar at the top shows scroll progress. Animations do not delay answering.

Every flashcard includes a technical definition, an original imagined training
analogy using Jujutsu Kaisen, Naruto, or Demon Slayer, and a Connect it note
explaining the OS mapping. These memory aids are not claims about show events.

CHALLENGE ACTIVITIES
Choose an activity, fill its fields, then press Check answers (or Enter).
Correct fields lock; incorrect fields show hints and can be corrected.
Incorrect field attempts are counted each time Check answers finds an error.
Show worked solution reveals the method, calculations, and every field answer
at any time. It does not fill your inputs or add mistakes. Examples revealed
before completion count as assisted, separate from independent completions.
Hide the solution, then use New variation to practice the method again.
New variation avoids the last 12 examples for that activity and changes values
or cases where appropriate; Export-based example
restores the source example. Some conceptual variations reorder prompts.
These are local recreations of the visible exported screens, not unseen
ZyBooks levels. Missing details and added assumptions are stated explicitly.
Activity progress lasts for this visit and is separate from exam history.

KEYBOARD
Practice: 1–4 selects the displayed answer; Enter advances after a correct answer.
Flashcards: Enter/Space reveals; 1 marks Again; 2 marks Got it.
Normal Tab navigation, Enter activation, and visible focus outlines also work.

SCORING
Every new incorrect option selected adds an incorrect attempt. Rejected options
are disabled so accidental repeat clicks do not add mistakes. A correct answer
locks the question and enables Next. There is no separate Submit step.

First-attempt accuracy = first-selection correct / questions attempted.
An attempted but unfinished question counts in the denominator. An untouched
question does not. Timed completions count as soon as the correct answer is
selected, even if Next has not been pressed.

A timed challenge continues while the tab is hidden. It stops at its wall-clock
deadline. Questions repeat only after the full bank has been exhausted; results
then count separate encounters. End session allows an early finish.

LOCAL HISTORY
History stays in this browser when local storage is available. Previously missed
questions remain in the mistake pool even after later successful reviews, so you
can revisit them. Sources & conventions includes a Clear history control.
History may differ between browsers or after moving the folder. If storage is
unavailable, history stays only for the current page visit. Active sessions and
flashcard ratings are not restored after closing or reloading the page.
